# React + Vite + Tailwind CSS

This project is a modern web application built with React, Vite, and Tailwind CSS.

## Features

- ⚡️ **Vite** - Lightning fast frontend tooling
- ⚛️ **React** - A JavaScript library for building user interfaces
- 🎨 **Tailwind CSS** - A utility-first CSS framework

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository

```bash
git clone <repository-url>
cd <repository-name>
```

2. Install dependencies

```bash
npm install
# or
yarn
```

3. Start the development server

```bash
npm run dev
# or
yarn dev
```

4. Open your browser and visit `http://localhost:5173`

## Build for Production

```bash
npm run build
# or
yarn build
```

## Preview Production Build

```bash
npm run preview
# or
yarn preview
```

## Customization

- Modify `tailwind.config.js` to customize your design system
- Edit `src/App.jsx` to change the main application
- Add your components in the `src/components` directory
